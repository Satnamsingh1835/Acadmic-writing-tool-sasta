# Workflows

source: inspect one source into JSON.
matrix: compare sources; export JSON/CSV/Markdown/SQLite.
debate-map: map source-specific positions supported by the corpus.
concept-map: track concept occurrences and definitions.
historical-synthesis: group evidence by period without asserting continuity.
gap-analysis: compare clusters and explicit limitations.
research-questions: derive questions from documented gaps.
audit: run traceability and overclaim checks.

Use python -m agent.cli --help.
